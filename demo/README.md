# Demostración de portafolio

Esta página es un prototipo interactivo y autónomo con catálogo y operaciones ficticias. No llama a Supabase ni a Nubefact; los cambios de inventario y ventas solo se muestran durante la sesión.

Demo publicada: https://distribuidora-mariva-demo.vercel.app/ . La carpeta incluye `vercel.json` para servir estos archivos HTML sin compilar la app completa.

La aplicación completa de Ionic/Angular está en la raíz del repositorio y requiere configurar un proyecto Supabase propio para ejecutarse.
